# 视觉必要性 · 双向判定

核心原则：**图只在语言效率不足时出现。**

这条规则必须双向执行。只抓「多余的图」会造出另一种烂东西——作者不敢放图，改用三段文字硬描述一个空间关系。两个方向同等扣分。

---

## 判定流程

```
这里有一张图 ──→ 它满足 V1/V2/V3/V4 任一条吗？
                    │
                    ├─ 否 ─→ 删掉。（不要改小、不要放角落，删掉）
                    │
                    └─ 是 ─→ 删掉它，我需要多讲几句话？
                              │
                              ├─ 0 句 ─→ 删掉（它只是重复文字）
                              └─ ≥1 句 ─→ 留下，检查有没有标注指向 message


这里没有图 ──→ 这段在描述空间关系／量的对比／流程／未见过的实物吗？
                    │
                    ├─ 否 ─→ 正常，不需要图
                    │
                    └─ 是 ─→ 用了几句话在描述？
                              │
                              ├─ ≤2 句 ─→ 可接受
                              └─ >2 句 ─→ 该上图却没上，扣分
```

## 四条通过条件

### V1 · 空间／结构关系
部件怎么装在一起、层次怎么叠、模块怎么连。

判准：**如果要用文字讲清楚，必须使用「上面」「里面」「连到」「夹在……之间」等方位词超过两次，就该画图。**

### V2 · 量的对比
趋势、占比、量级差、分布。

判准：三个以上数字要互相比较时，图优于文字。两个数字的对比，一句话就够，不必画图。
（图表本身的设计另有规范 → 见 `dataviz` skill）

### V3 · 时序／流程
步骤、演进路径、状态转换、信号流向。

判准：步骤超过 4 步，或存在分支/回路时，画图。线性 3 步用文字讲更快。

### V4 · 实物长相
读者没见过这东西，必须让他看一眼。

判准：这是唯一一条「照片」能通过的条件。谐波减速器长什么样、晶圆厂洁净室长什么样——给一张真实照片。注意：**给了照片就要圈出重点**，一张没有标注的设备照片仍然什么都没说。

## 装饰图鉴（命中即删）

| 类型 | 具体表现 |
|---|---|
| **Stock photo** | 握手、齿轮、发光的大脑、蓝色数据流、地球加线条、西装背影看城市 |
| **图标列表** | 每个 bullet 前面配一个小图标，图标与内容无关 |
| **形状包装的清单** | 金字塔、循环箭头、三角形、同心圆里塞进几个词——把清单画成形状，不增加任何信息 |
| **无标注截图** | 贴了一张界面截图/仪表板，没有圈出要看哪里 |
| **概念方块图** | 一堆方框连线，每个框里是抽象名词，说不清任何具体机制 |
| **3D 图表** | 立体柱状/立体饼图，透视失真让数字更难读 |
| **背景配图** | 半透明大图垫在文字后面 |
| **公司 Logo 墙** | 「我们的合作伙伴」，除非在讲市场结构，否则零信息 |
| **重复文字的图** | 图里的字和旁边的文字一模一样 |

## 该上图却没上（反向清单）

以下情况出现在纯文字段落里，就是缺图信号：

- 连续两句以上使用方位词描述结构（「A 装在 B 上面，B 通过 C 连到 D」）
- 罗列三个以上数字并要求读者心算比较
- 描述超过 4 个步骤的流程，或流程有分支
- 提到一个读者极可能没见过的实物，却只有名词
- 用文字描述图形／波形／曲线的形状（「先陡升然后趋于平缓」）

---

## 留下来的图要过的四关

1. **一图一 message** — 这张图要讲的那一件事是什么？说不出来就是图没设计好。
2. **标注指向 message** — 高亮、箭头、圈选。没有标注的图等于把找重点的工作丢给读者。
3. **图题是断言句** — 图题写「2020–2025 年产能变化」（❌）还是「产能翻了四倍，但良率没动」（✅）。
4. **能独立看懂** — 遮住正文，光看图和图题能懂吗？

## 关于 Interactive HTML 的额外规则

HTML 交付物多一层诱惑：动效、滚动视差、悬停展开。同一条原则照样适用——

- **动效必须承载信息**：过程动画（展示装配顺序、数据流动）通过；淡入、飞入、打字机效果不通过。
- **渐进揭示要对应悬念**：折叠内容的展开必须对应「S2 段落钩链」里的某个问题，不能只是为了让页面看起来短。
- **可交互 ≠ 有信息**：一个能拖动的滑杆，如果拖动后读者学不到新东西，它就是装饰。
- **禁止纯装饰的粒子背景、渐变光斑、鼠标跟随效果。**
