# 逐字稿格式与时间估算

## 时间估算

| 场景 | 语速 |
|---|---|
| 影片口播／配音 | 250 字／分钟 |
| 现场讲述（含停顿与临场反应） | 200 字／分钟 |
| Workshop（含操作演示） | 150 字／分钟 |

估算时用**中文字数**（不含标记）。给总时长时标明用的是哪一档。

现场场景要留 15% 缓冲——现场一定比排练慢。

---

## 标记

| 标记 | 用途 |
|---|---|
| `[画面：X]` | 此刻画面上应该出现什么。X 要具体到「第 5 页的良率曲线」，不是「相关图表」 |
| `[停顿]` | 停 1–2 秒 |
| `[强调]` | 这句放慢、加重 |
| `[互动：X]` | 停下来向听众提问或让他们动手，X 是具体的提问／任务 |
| `[来源：X]` | 这个数字的出处，念稿时不念出来，供事后查核 |

---

## 输出格式

```markdown
# 〈标题〉逐字稿

**估算**：12 分 30 秒（现场档 200 字/分）｜正文 2,500 字

---

## 00:00 开场｜钩子

它能空翻。你在短视频上看过——后空翻、落地、稳住。[停顿]

但它接不住一片落叶。[强调]

[画面：并排两段影片，左边空翻，右边手掌僵在半空]

差别在哪？这就是今天要拆的东西。

---

## 00:45 第一段｜为什么「轻」比「重」难

〈本段回答：为什么精细动作反而更难〉
〈本段抛出：那到底卡在哪个零件上〉

... 正文 ...

[来源：某某报告 2025]
```

**每段开头必须写两行角括号注记**：本段回答什么问题、抛出什么新问题。这两行不念出来，是骨架的可视化——写不出来的段落就是资讯堆叠，回去改结构，不要硬写。

段落长度控制在 60–90 秒（现场档约 200–300 字）。超过就拆。

---

## Workshop 场景补充

多加一层节奏标记：

- 每个 `[互动：X]` 要写清楚**预期产出**（学员做完手上有什么）和**预计耗时**。
- 演示步骤用独立行标 `[操作：X]`，一行一步，方便讲者边念边做。
- 在需要等待的地方标 `[等待：X 分钟]`，并写清楚等待期间讲者说什么——冷场都发生在这里。

---

## 回填讲者备注

要写回 .pptx 的 speaker notes 时：

- 按页切分，一页一段。
- 保留 `[画面]` `[停顿]` `[互动]` 标记。
- 去掉角括号注记（那是给作者看的，不是给讲者看的）。
- 用 `pptx` skill 执行写入。
