# 样板契约

`assets/index.template.html` 是通用的，**不要为了单一领域去改它**——需要的差异都走 `META`。唯一的注入点是 `/*__TREE_JSON__*/`，`build.py` 会把 `{meta, nodes, quiz}` 整包塞进去。

产出是**单一自足档案**，直接发布成 Artifact。因此有三条硬性约束：

1. **不能有 `<!DOCTYPE>` / `<html>` / `<head>` / `<body>`** —— Artifact 会自行包覆。样板从 `<title>` 开始。
2. **不能依赖 `height:100%` 的父层链** —— 内容被包进宿主的 body，链会断。用 `100dvh`。
3. **页面自己发起的下载会被 sandbox 挡掉** —— `<a download>`、blob URL、script 触发的存档在 viewer 端全部无效。所以进度是「可复制的 JSON 文字」而不是下载档，汇入是「贴上再载入」而不是 file input。

CSP 也会挡掉所有外部 host：CDN、webfont、远端图片、fetch 一律不行。

## 节点视觉

| 状态 | 判定 | 视觉 |
|---|---|---|
| `lock` | 有前置未点亮 | 灰、🔒、压暗——**看得见但摸不到**，这是驱动力的来源，不要藏起来 |
| `avail` | 前置全通、未开始 | 章节色边框 + 光晕 |
| `prog` | 有勾任务或答过题 | 橘边 + 百分比数字 |
| `done` | 任务全勾（+ 题库过关） | 金色实心 + ✓ |

边：两端都 done = 金色实线；起点 done = 蓝色；否则灰。任一端是 side = 虚线。

## 互动

| 操作 | 行为 |
|---|---|
| 拖曳／滚轮／双指 | 平移／缩放（0.18–2.2 倍，以游标为锚点） |
| 進度 | 开对话框，秀出整包进度 JSON，可复制、可贴回载入 |
| 說明 | 开对话框，操作表 + 节点视觉表（页面自带，所以不必另附 README） |
| 点节点 | 开右侧面板。拖曳过就不触发点击（`dragMoved` 判定） |
| 勾任务 | 立刻存档、重算 XP 与解锁；点亮时跳 toast |
| ▶ 下一步 | 优先跳 `prog`，其次主线 `avail`，再其次任意 `avail` |
| 定位 | 回到「目前该做的节点」，缩放到看得清标签 |
| 全览 | 缩到整棵树入镜 |
| 搜寻 + Enter | 比对 title/en/desc/id，跳到第一个命中 |
| 图例列 | 点章节跳到该章第一个节点 |
| ⚔ 试炼 | 开题库覆盖层；Esc 关闭 |
| 重置作答 | 清掉**目前筛选范围**内的作答。见下方「重置的粒度」 |
| 面板的「练这个节点的题」 | 开题库并筛到该节点 |

## 试炼区

- 筛选：全部 / 各章 / **只看错题** / 只看未答（+ 从面板进来时的节点筛选）
- 一次一题，答完立刻判定：正解绿、选错红且同时点亮正解
- 展开 `ex`，下方是深挖 prompt 区块（等宽字 + 复制钮，复制后变「已复制」两秒）
- **错题集是回访理由**，一定要能只刷错题

## 重置的粒度

答错之后想重刷，唯一的出口不能是「清空整棵树」——那会连任务勾选一起赔掉，
结果就是没人敢按，错题永远卡在那里。

试炼区的「重置作答」清除范围**跟着目前的筛选走**，一颗按钮覆盖所有粒度：

| 当前筛选 | 清掉 |
|---|---|
| 某一章 | 该章的全部作答 |
| 某个节点（从面板的「练这个节点的题」进来） | 该节点的作答 |
| 只看错题 | 全部错题 |
| 全部 | 整份题库的作答 |

三条硬性约束：

- **只删 `S.ans`，不碰 `S.done`。** 任务勾选与题目作答是两套进度，重置题目不该牵连任务。
- **连按两次确认。** 第一次显示将清除的题数并转成警示色，4 秒内没有第二次就自动取消。
  这是破坏性操作，但也不值得为它开一个对话框。
- **`quiz_gate` 开着时要重算节点状态。** 清掉作答后，已点亮的节点必须退回 `prog`，
  否则会出现「题目没答却还是金色」的假进度——所以处理函式里 `render()` 与 `renderQ()` 都要叫。

HUD 上那颗「重置」是另一回事：它清空整包进度（`S={done:{},ans:{}}`），保留给真的想重来的人。

## 进度

`localStorage`，key 来自 `META.storage_key`：

```js
{ done: {nodeId: [taskIdx,...]}, ans: {qid: {p: pickedIdx, ok: bool}} }
```

读取包 `try/catch`，坏掉就当空的重来。**汇出是下载 json、汇入是读档**——这样进度能 commit 进 repo，换装置或清快取都救得回来。

## XP

`XP = Σ(任务完成比例 × hours × 10) + 答对题数 × 5`，每 `xp_per_level` 升一级，称号取 `META.titles` 里最后一个满足的。

时数是估计值，所以 XP 也是估计值——它的作用是给回馈节奏，不是精算。

## 要改样板的时候

只有两种情况值得改：加一种**新的节点状态**，或加一个**新的资料栏位**。其余的（配色、章名、称号、闸门开关、深挖 prompt 措辞）全部走 `META`。

改了样板记得：所有用它产生的树都会跟着变，而 `index.html` 是产生物——**永远重跑 `build.py`，不要手改 index.html**。
