# 叙事骨架规格

这是 `deck-audit`、`deck-script`、`deck-build` 三个 skill 共用的规格底座。**它本身不执行任务**，只提供判准。

风格基准：硅谷101的深度视频——一条骨干贯穿全篇、靠悬念而非目录推进、抽象立刻落地、图片只在语言效率不足时出现、每一页都有信息增量。

## 五个维度

| | 维度 | 一句话 |
|---|---|---|
| S1 | 骨干 | 全篇一条主轴，每段都在推进它 |
| S2 | 悬念 | 靠未解的问题推进，不靠目录 |
| S3 | 具体性 | 抽象论点立刻被具体事实钉住 |
| S4 | 视觉必要性 | 图只在语言效率不足时出现（双向检核） |
| S5 | 信息增量 | 每一页都携带新信息 |

各 25 分制，判定阈值与完整检核动作见 `references/rubric.md`。

## 使用这份规格时的铁律

1. **每条判定附证据**——页码/段落 + 原文引用。
2. **每条扣分附改写**——给出改写后的具体文字，不写「建议加强逻辑性」。
3. **S1 不足 3 分时停止修补 S2–S5**——骨干错了，局部润色无意义。
4. **不为凑分而扣分**。

## 已知限制

本规格针对**叙事型深度内容**设计。用于教学型 workshop 材料时，「议程页」「回顾页」「悬念驱动」三处会产生误判。当前采用单一标准、不分 profile：命中时在报告的「已知限制」区块列出，交由人判断，不自动豁免。详见 `references/antipatterns.md` 末节。
