# 叙事规格 · 评分表

整套 skill 的唯一评分依据。检核、生成、逐字稿三条路径都以此为准。

风格基准取自硅谷101的深度视频：**一条骨干贯穿全篇、靠悬念而非目录推进、抽象立刻落地、图片只在语言效率不足时出现、每一页都有信息增量。**

---

## 四条使用原则

**1. 每条判定必须附证据。** 页码/段落编号 + 原文引用。没有证据的评语一律作废，不写进报告。

**2. 每条扣分必须附改写。** 给出改写后的具体文字。禁止出现「建议加强逻辑性」「可以更聚焦」「层次感不足」这类无法执行的评语——这类句子是审查者偷懒的标志。

**3. 诊断有顺序：S1 不足 3 分时，停止修补 S2-S5。** 骨干错了，局部润色没有意义；重排骨干会让一半的局部问题自动消失。报告必须把这句话写在最前面，而不是照样列 40 条零散建议。

**4. 不为凑分而扣分。** 做得好就给 5 分。一份满分报告比一份为显得专业而硬挑毛病的报告有用。

---

## S1 · 骨干（Spine）

> 全篇有且只有一条主轴，每一段都在推进它。

### 检核动作

- **S1.1 一句话测试** — 用不超过 30 字说出全篇主轴。说不出来，或需要用「以及」「另外」连接两件事，即失败。
- **S1.2 标题链测试** — 把所有页/段标题抽出来单独排成一列，遮住内容只读标题。**能不能读成一篇连贯的摘要？** 这是最有效的单一测试。
- **S1.3 孤儿检测** — 逐页问「删掉这页，主轴断不断？」不断 = 孤儿页，标记出来。
- **S1.4 轴型判定** — 属于四种横轴之一（拆解／因果／时间／对比，见 `spine-patterns.md`）。中途换轴要标记：换轴 = 观众重新定位，代价很高，必须有明确理由。
- **S1.5 可换序检测** — 任取相邻两段交换顺序，如果读起来一样通顺，说明它们是并列关系而非推进关系。并列越多，骨干越弱。

### 评分锚点

| 分 | 状态 |
|---|---|
| 0 | 一堆并列主题，页面可任意换序而不影响理解 |
| 1 | 有隐含组织逻辑但从未说出，观众得自己拼 |
| 2 | 主轴存在，但被 3 个以上孤儿段落打断 |
| 3 | 主轴清楚，有 1–2 个孤儿 |
| 4 | 主轴清楚、无孤儿，但选错轴型（例如该用因果链却排成时间流水账） |
| 5 | 标题链单独抽出来读，本身就是一篇完整摘要 |

## S2 · 悬念（Tension）

> 靠「未解的问题」推进，不靠目录推进。

### 检核动作

- **S2.1 冷开场** — 开篇第一屏是不是一个具体、反直觉、有画面的事实或场景？（写法见 `hooks.md`）
  出现「大家好，今天我要分享」「随着 AI 的快速发展」「首先介绍一下背景」「本次议程」= 0 分开场。
- **S2.2 段落钩链** — 逐段填两栏表：

  | 段 | 本段回答什么问题 | 本段抛出什么新问题 |
  |---|---|---|

  **填不出「回答什么问题」的段落，就是资讯堆叠而非叙事。** 这张表本身要放进审查报告，它比任何评语都直观。
- **S2.3 承接张力** — 段落之间是否用「但问题在于」「这里有个关键」「然而事情没这么简单」承接，而不是「接下来我们看第二部分」。
- **S2.4 悬念要有真实落差** — 反向检核：张力词后面必须真的有认知反转。用「但是」接一句毫不意外的话，是廉价悬念，比没有更糟，要扣分。
- **S2.5 闭环** — 结尾是否回到开场的钩子并给出解答。

### 评分锚点

| 分 | 状态 |
|---|---|
| 0 | 从问候/议程/背景开场，全篇平铺直叙 |
| 1 | 有开场钩子，但之后完全靠章节目录推进 |
| 2 | 前段有张力，中段塌成资讯罗列 |
| 3 | 多数段落有钩链，但有廉价悬念（张力词后无实际反转） |
| 4 | 钩链完整，张力真实，但结尾没有回到开场 |
| 5 | 每段都能填满钩链表，张力有真实落差，结尾闭环 |

## S3 · 具体性（Concreteness）

> 抽象论点必须立刻被具体事实钉住。

### 检核动作

- **S3.1 抽象词密度** — 统计这类词的出现次数：
  `生态 赋能 协同 闭环 抓手 沉淀 心智 势能 壁垒 底层逻辑 深度融合 全面提升 加速推进 助力 打通 重塑 引领 数字化转型 战略高度`
  每千字超过 8 次即扣分，并逐个列出所在位置。
- **S3.2 落地间距** — 每个抽象论点之后 **2 句之内**是否落到：具体数字 / 具体公司 / 具体人 / 具体场景 / 具体物件？超过 2 句仍在抽象层滑行 = 扣分。
- **S3.3 术语首现类比** — 每个专有名词第一次出现时，是否给了生活化解释？
  ✅「谐波减速器，你可以想成机器人的关节，它决定了这只手能多稳」
  ❌「采用高精度谐波减速器方案」
- **S3.4 数字有锚** — 数字必须带对比基准，否则读者无法判断大小。
  ❌「年产能 50 万台」
  ✅「年产能 50 万台——是去年全球总量的三倍」
- **S3.5 可验证性** — 每个关键事实能否被追溯？来源不明的断言要标记（不一定扣分，但要在报告中列出待补来源清单）。

### 评分锚点

| 分 | 状态 |
|---|---|
| 0 | 通篇抽象，读完说不出任何一个具体事实 |
| 1 | 只有零星具体内容，且与论点脱节 |
| 2 | 有具体例子，但例子没在支撑论点（举例是装饰） |
| 3 | 多数论点有具体支撑，但数字普遍缺锚 |
| 4 | 论点都被钉住、数字有锚，但术语首现缺类比 |
| 5 | 每个论点被至少一个可验证的具体事实钉住，术语即时翻译 |

## S4 · 视觉必要性（Visual Necessity）

> 图只在语言效率不足时出现。**这条必须双向检核。**

只抓「多余的图」会导向另一种失败：作者不敢放图，改用文字硬描述空间关系。两个方向同等扣分。

### 四条通过条件（至少满足一条才留）

| | 条件 | 说明 |
|---|---|---|
| **V1** | 空间／结构关系 | 部件怎么装在一起、系统各层怎么叠 |
| **V2** | 量的对比 | 趋势、占比、量级差 |
| **V3** | 时序／流程 | 步骤、演进路径、状态转换 |
| **V4** | 实物长相 | 读者没见过这东西，必须让他看一眼 |

### 检核动作

- **S4.1 冗余图** — 逐张问：**「删掉它，我需要多讲几句话？」答案是 0 → 删。**
- **S4.2 缺图（反向）** — 逐段问：有没有段落在用文字描述 V1–V4 之一？**用文字描述空间关系连续超过 2 句 = 该上图却没上。**
- **S4.3 图不是文字容器** — 满屏 bullet 的版面不算图。金字塔/循环箭头/三角形里塞词也不算——那是把清单画成形状，没有增加任何信息。
- **S4.4 一图一 message** — 每张图只讲一件事，且标注/高亮指向那件事。截图没有圈重点 = 未完成的图。
- **S4.5 装饰图鉴** — 见 `visual-necessity.md` 的反模式清单，命中即列出。

### 评分锚点

| 分 | 状态 |
|---|---|
| 0 | 图全是装饰；或该有图的地方全用文字硬讲 |
| 1 | 多数图无功能，或多处明显缺图 |
| 2 | 功能图与装饰图各半 |
| 3 | 多数图有功能，混了 2–3 张装饰图，或漏了 1–2 处该上图 |
| 4 | 图都通过 V1–V4，但有图缺标注/未指向 message |
| 5 | 每张图都通过 V1–V4，无一处用文字硬描述视觉关系，每图一 message 且有标注 |

## S5 · 信息增量（Density）

> 每一页都要携带新信息。

### 检核动作

- **S5.1 零增量页** — 统计这些页面的占比：议程页、章节封面页、「谢谢聆听」、「关于我们」、「Q&A」、纯装饰过场。
- **S5.2 标题是断言句** — 页标题应该是那页的结论，不是那页的话题。
  ❌ 名词短语：「供应链的三个瓶颈」
  ✅ 断言句：「减速器良率卡在 60%，这才是量产的真瓶颈」
  **快测：只读标题能不能知道结论？** 不能，就是名词短语。
- **S5.3 重复检测** — 同一信息在多页重复出现（含「回顾一下前面」）。
- **S5.4 一页一 message** — 一页塞两个以上不相关论点 = 拆页或删。
- **S5.5 过渡废话** — 「接下来」「我们来看看」「值得一提的是」占据独立页面或独立段落。

### 评分锚点

| 分 | 状态 |
|---|---|
| 0 | 超过 30% 页面零增量 |
| 1 | 20–30% 零增量，标题全是名词短语 |
| 2 | 10–20% 零增量 |
| 3 | 仅保留必要的仪式性页面，主体页都有增量，但标题多为名词短语 |
| 4 | 无零增量页，多数标题是断言句 |
| 5 | 无零增量页，每页标题就是那页的 message，无重复 |

## 总分与判定

满分 25。

| 总分 | 判定 | 行动 |
|---|---|---|
| 21–25 | **可交付** | 只列 nice-to-have |
| 15–20 | **需修** | 列出必修项，逐条给改写 |
| ≤14 | **重做骨架** | 只谈 S1，其余暂缓 |

**覆盖规则：S1 ≤ 2 时，无论总分多少，一律判定为「重做骨架」。**

## 五分钟快测（不做完整评分时用）

1. 把标题抽成一列，读得通吗？
2. 第一屏是钩子还是问候？
3. 随机翻三页，每页的标题是断言还是名词？
4. 随机挑三张图，删掉后需要多讲话吗？
5. 随机挑三个论点，两句内落地了吗？

五题中错两题以上 → 值得跑完整检核。

## 报告格式要求

审查报告必须包含且只包含这些区块，顺序固定：

1. **判定** — 一句话结论 + 总分 + 三档判定
2. **骨架还原** — 主轴一句话、轴型、标题链、孤儿页标记
3. **钩链表** — S2.2 的两栏表，完整列出
4. **维度评分** — 五个维度各自的分数与关键证据
5. **必修清单** — 按严重度排序，每条含：位置 / 症状 / 原文 / **改写后文字**
6. **待补来源** — S3.5 标记的无来源断言

不加「总体而言这是一份不错的简报」这类开场白，不加鼓励性结语。
