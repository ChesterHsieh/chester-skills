# 口语规则

书面语和口语是两种语言。把书面稿念出来，听众会在第三句掉队。

---

## 句子

- **一句 25 字以内。** 超过就断成两句。中文没有从句缓冲，长句念出来听众来不及在脑中断句。
- **主动语态。** 「这个方案被团队否决了」→「团队否决了这个方案」。
- **一句一件事。** 出现第二个「的」字结构套嵌，就该断。
- **动词开头优于名词开头。** 「减速器的良率问题导致了量产的延迟」→「减速器良率上不去，量产就往后推」。

## 禁用（书面连接词）

| 禁用 | 改成 |
|---|---|
| 此外／另外值得一提的是 | 还有一件事 ／ 直接讲下一件 |
| 综上所述／由此可见 | 所以 ／ 这说明 |
| 不难看出／显而易见 | 删掉，直接说结论 |
| 基于上述原因 | 因为这个 |
| 首先／其次／再次／最后 | 只在真的需要编号时用，多数时候删掉 |
| 在……的背景下 | 删掉 |
| 进行／予以／加以 + 动词 | 直接用那个动词 |

## 转场句库

按功能挑，不要每段都用同一句。

**推进** — 「所以问题就来了」／「这就带出下一件事」／「顺着这个往下」

**反转** — 「但事情没这么简单」／「这里有个关键」／「问题就出在这」／「听起来合理，但……」

**收束** — 「所以回到刚才那个问题」／「这就是为什么……」／「答案是……」

**降落到具体** — 「举个实际的例子」／「具体有多难？这么说吧……」／「换成数字来看」

**承认不确定** — 「这一段我得说清楚，是推测」／「公开资料只到这里」

**禁止**：「接下来我们看第二部分」「让我们进入下一个章节」——这是目录推进，不是悬念推进。

## 数字

- **口语化写出来**：`35,000,000` → 「三千五百万」。逐字稿是给人念的，不是给人看的。
- **锚要说全**：「五十万台——去年全球总量的三倍」。听众无法回看，锚和数字必须在同一口气里。
- **精度降级**：「62.7%」念成「六成多一点」。除非精度本身是重点。

## 术语

- 首次出现：中文 + 英文 + 一句类比。「谐波减速器，harmonic drive，你可以想成机器人的关节，它决定这只手能多稳。」
- 之后固定用一种叫法，不要中英混着换。
- 一段里出现三个以上新术语 = 听众过载，拆段或砍掉一个。

## 口头禅

**可以有**（口语的自然度来自这些）：
- 直接称呼「你」
- 短促的确认句：「对」「就是这样」
- 重复关键词强调：「慢，非常慢」

**要控制**（每千字不超过 3 次）：
- 「那么」「其实」「就是说」「这个东西」「基本上」

**删掉**：
- 「众所周知」「我个人觉得」（内容本来就是你的判断）
- 「不知道大家有没有听过」（问了也没人答，纯延迟）

## 停顿

在这三个位置标 `[停顿]`：

1. 抛出钩子之后 — 让问题落地
2. 给出反转之前 — 制造落差
3. 一个大段落结束 — 给消化时间

一分钟内超过三个停顿 = 节奏拖沓。
