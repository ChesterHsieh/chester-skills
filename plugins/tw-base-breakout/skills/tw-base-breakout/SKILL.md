# 台股支撐區型態粗掃

用戶的觀點（取自他的三張圖、8–10 月個股期貨成交紀錄與後續確認，細節見 [references/pattern.md](references/pattern.md)）：

> 股價在前波低點上方築出**平穩的價格支撐區**，底線被反覆測試守住 →
> 短中期均線（5/20/60）**糾結**、長線 MA120 **上彎**（不要求站上）→ 最後突破平台上緣。
> **進場點是貼近支撐區底線**。急跌洗盤常見但不是必要條件。

用途是**粗掃**：從一串股票裡挑出值得打開線圖細看的幾檔。不是投資建議、不下單。

## 1. 決定要掃哪些股票

| 用戶給的 | 怎麼做 |
|---|---|
| 代碼（一檔或多檔） | 直接帶進去 |
| 股票名稱 | 換成代碼，不確定就問 |
| 題材（「AI 伺服器」「重電」） | 用你的知識列出該題材的台股上市櫃成分股代碼（不夠把握就 WebSearch），**在回覆裡列出你用了哪些股票**，讓用戶能補漏或刪掉 |
| 「全部個股期貨」「期貨標的」 | `--universe ssf` |
| 清單檔 | `--file 路徑`（空白／逗號／換行分隔，`#` 後是註解） |

**個股期貨篩選**：用戶交易個股期貨。題材或清單掃描時，如果他沒說要不要排除沒有個股期貨的股票，
用 AskUserQuestion 問一次：「只留有個股期貨的（`--futures-only`）」或「全部都看、標註有沒有期貨」。
同一段對話裡已經回答過就沿用，不要重問。單檔查詢不用問，直接顯示期貨欄位。

## 2. 跑掃描

```bash
S="$SKILL/scripts/scan.py"
python3 "$S" 2330                                # 單檔：完整明細
python3 "$S" 2382 3231 2356 6669 2376 3017       # 多檔：摘要表，依符合度排序
python3 "$S" 2382 3231 6669 --futures-only       # 只留有個股期貨的
python3 "$S" --universe ssf --only entry         # 全部個股期貨標的，只列進場區
python3 "$S" 5483 --asof 2026-09-16              # 回測：假裝今天是那天
```

`$SKILL` 是這份 SKILL.md 所在目錄。只用 Python 標準函式庫。其他選項：`--only match`（只列符合／部分）、
`--detail`（多檔也印完整明細）、`--no-futures`、`--json`。

- ≤8 檔：逐檔抓（上市／上櫃自動判斷）
- \>8 檔：改抓**全市場逐日行情**。第一次要建快取，約 3–4 分鐘（stderr 會印進度）——
  跑之前先跟用戶說一聲；之後每天只補當天，整個個股期貨池重跑約 2 秒
- 快取在 `~/.cache/tw-base-breakout/`

## 3. 回覆用戶

**粗掃（多檔）**：開頭一句「掃了 N 檔，符合 X、進場區 Y」，然後：

1. **🎯 進場區清單放最前面**（符合＋貼近底線）：代碼、名稱、收盤、底線、距底線、失效價、期貨保證金
2. 其他「符合」的依位置分組：逼近上緣（等突破）／剛突破／追高
3. 「部分符合」只列名稱＋沒過的那一項，一行一檔
4. 不符合的不用列，給數字即可
5. 題材掃描要附上「這次用了哪些股票」

**單檔**：一行結論（符合／部分／不符＋位置），關鍵價位，沒過的項目與意義，期貨資訊。

位置的意思：

| status | 意思 |
|---|---|
| `base_floor` 🎯 | 貼近支撐區底線（底線 +4% 內）：**用戶要的進場點**，失效價就在附近 |
| `base_mid` | 平台中段：沒有位置優勢，等回到底線 |
| `base_ceiling` | 逼近上緣：等突破，或等回到底線 |
| `breakout` | 剛突破：看突破日量比 |
| `pullback` | 突破後跌回平台：突破失敗的前兆 |
| `extended` | 離上緣 >15%：型態對但位置已經過了 |
| `failed` | 收盤跌破底線 3%：支撐失效 |

「平台尚短」（10–19 日）要明講：支撐還沒被驗證夠久，8 月中那批進場就是這種狀態。

## 4. 用戶不同意判讀時

問清楚是哪一段不一樣，對照 [references/pattern.md](references/pattern.md)，調整
`scripts/pattern.py` 的 `Params`（每個門檻都有註解），用 `--asof` 對用戶的成交日回測確認，
把校正理由補進 pattern.md，再跑 `python3 -m pytest -q "$SKILL/tests"`。

## 限制（視情況提醒）

- 價格未做除權息還原，平台期間遇除息會讓底線偏低
- 只看日線量價，不看籌碼、營收、題材強弱、大盤
- 規則是用少數個股、一段行情校出來的，不是統計驗證過的勝率
- 期貨保證金 = 收盤 × 契約股數（一般 2,000／小型 100）× 期交所原始保證金比例，是估算值
