# 判讀規則與書中出處

來源：John J. Murphy，*Technical Analysis of the Financial Markets*（1999）。頁碼是書上印的頁碼。
這裡只整理成規則清單（用自己的話），不是原文。每條後面是對應的 `Params` 門檻。

## 1. 先分模式：上升趨勢中的回檔，還是下跌後打底

| 模式 | 判斷 | 出處 |
|---|---|---|
| 回檔（pullback） | 從這段漲勢起點算，回吐 ≤ 2/3 | p.85–86：強勢修正常回 1/3～2/3，50% 最常見；超過 2/3 比較像反轉 |
| 打底（bottoming） | 回吐 > 2/3，或資料看不到漲勢起點 | — |

`pullback_max_retr = 0.66`

兩種模式的進場邏輯不同：
- **回檔**：33–50% 區是買進參考區（p.85），40–60% 回檔可以新建或加碼（p.402）。進場可以早一點。
- **打底**：一定要等底部確認，而且底部比頭部更需要量（p.110）。

## 2. 底部確認的四步（p.57–58 圖 4.4b；雙重底 p.117–122）

1. **①** 前低：下跌中的最低點
2. **② X**：從 ① 反彈後第一次回頭的高點，這就是確認線。**要等行情走出來，不能事先指定**
3. **③** 回測守在 ① 之上（低點墊高）
4. **④** 收盤突破 X → 底部成立

變形：
- **破底翻**：③ 比 ① 略低，但不超過 3%，然後收回（p.64 的 3% 有效跌破標準；p.122 多頭陷阱的鏡像）。
  `break_pct = 0.03`
- 只有一個低點、還沒出現回測時，**下降過程中最近的反彈高點**就是第一關（p.56–57：下降趨勢裡高點越來越低，
  突破最近一個較低高點是趨勢改變的第一個警訊）。

## 3. 突破的過濾條件

| 條件 | 出處 | 門檻 |
|---|---|---|
| 看收盤，不看盤中 | p.107、p.122 | — |
| 價格過濾 1–3% | p.64、p.107、p.122 | `filter_pct = 0.01` |
| 兩日規則：連兩天收在上方 | p.107、p.122 | — |
| 突破要放量 | p.110（底部必須）、p.164（所有型態） | `vol_strong = 1.2` |

**過濾條件不是萬無一失**（p.122）：會減少假訊號，但不會消滅它。

## 4. 量

| 規則 | 出處 |
|---|---|
| 價漲量增＝強；價漲量縮＝弱；價跌量增＝弱；價跌量縮＝強 | p.161 價量表 |
| 上升趨勢中，上漲時量大、回檔時量小；下降趨勢反過來 | p.162–164 |
| 價格創高但量縮＝背離，買盤在減弱 | p.163 |
| 量先於價：壓力消退會先出現在量 | p.165 |
| OBV 方向要跟價格一致，不一致就是背離 | p.165–166 |
| 底部的突破，大量是必要條件；頭部不一定 | p.108、p.110 |

`updown_window = 10`、`vol_window = 20`、`vol_weak = 0.8`

**跨市場掛牌的股票不能只看一個市場的量**，見 [global-volume.md](global-volume.md)。

## 5. 反轉日與賣壓竭盡

- 底部反轉日：盤中創波段新低，收盤高於前一天（p.91）
- 震幅越大、量越大，訊號越強；同時是外側日更有意義（p.91–92）
- 爆量的版本叫 selling climax：不一定是最後的底，但通常代表一個重要低點已經出現（p.92、p.175）
- 週反轉比日反轉重要，月反轉又更重要（p.93）

`reversal_lookback = 10`、`reversal_scan = 15`

## 6. 缺口（p.94–97）

- 突破缺口：出現在型態完成時，通常有大量，多半不會回補
- 向上缺口之後是支撐；收盤跌回缺口下方是轉弱訊號
- 財報常製造缺口；這本書沒有另外的事件模型，原則是「價格已經反映已知資訊」（p.2–6）

## 7. 支撐與壓力

- 被有效跌破的支撐會變成壓力，反之亦然（p.59–61）
- 越近期、停留越久、量越大的價位越重要（p.60）
- 整數關卡常是心理支撐壓力；不要把停損剛好放在整數上（p.64）

## 9. 型態大小與時間

- 型態越大（越寬、越久、震幅越大），後面的走勢越大（p.100–101）
- 底部通常比頭部花更久時間，震幅也較小（p.101）
